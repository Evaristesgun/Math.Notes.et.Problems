# Math.Notes.et.Problems

It is my repository for Linear Algebra, Exponent Sum, etc. lecture-style notes and adjunctive exercises, which mainly based on my independent chain of theorems, definition and correlated remarks. 

## Online PDFs

Linear Algebra -- from _Linear Algebra and Geometery_ by _Shafarevich_, _Exercise in Algebra_ by _Kostrikin_, Multiple resources by Prof. _Gilbert Strang_, and _Axler_.

link: https://Evaristesgun.github.io/Math.Notes.et.Problems/LinearAlgebra/main.pdf

Exponent Pairs -- _Van der Corput's Method of Exponential Sums_ by _S. W. Graham_ from Michigan Technological University, USA and _G. Kolesnik_ from California State University, Los Angeles, USA.

link: https://Evaristesgun.github.io/Math.Notes.et.Problems/ExPair/main.pdf
