This is the exponent pair project. It covers basic application estimating exponent sums as well as Van der Corput's method, including _A, B process_. 

In addition, I addressed some typical number theory problems:
1. Exercise in _Harvard Lecture Notes- "Exponential sums III- the van der Corput" by Noam Elkies_,
2. Exercise 3, 4, 5 in _Terrence Tao "254A, Notes 5: Bounding exponential sums and the zeta function"_.

The Note incorporates a custom notation set, please refer to **src/mymath.sty**.
